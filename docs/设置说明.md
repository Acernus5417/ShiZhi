# 拾址 · 设置说明

入口：刊头 ⋮ → **设置**。

设置首页只列出三个栏目，点进去才看到具体内容，左上角「‹ 设置」返回，`Esc` 同效。

| 栏目 | 内含 | 首页右侧显示 |
| --- | --- | --- |
| 自定义 | 主题 / 背景 / 浏览器联动 | 主题 · 背景 · 浏览器联动 |
| 习惯词典 | 已记住的域名列表 | 条数 |
| 分类管理 | 增加 / 删除分类 | 个数 |
| AI 配置 | 开关 / 接口地址 / API Key / 模型 / 测试连接 | 未开启 / 已开启 / 待补全 |

## 自定义

### 主题
五套主题，点色块即换，右侧显示当前主题名。刊头的小月亮只在「纸 ↔ 夜读」之间快捷切换。

| 主题 | 基调 | 自带背景 | 强调色 | 卡片 |
| --- | --- | --- | --- | --- |
| 纸 | 暖纸白 · 亮 | 无 | 朱红 | 不透明 |
| 夜读 | 暖墨底 · 暗 | 无 | 暖朱 | 不透明 |
| 暮色 | 黄昏赭橙 · 亮 | 有 | 赭红 | 半透明 |
| 松墨 | 深林墨绿 · 暗 | 有 | 竹青 | 半透明 |
| 夜航 | 靛蓝夜空 · 暗 | 有 | 跑道黄 | 半透明 |

带背景的主题会 simultaneously 应用虚化与暗化滤镜，同一张图因遮罩色不同而呈现不同气氛。

### 背景
- 「选择图片…」→ 裁剪器：**画布比例与窗口一致**，拖动图片调整位置、缩放 100–400%，确认后按该比例裁剪并铺满整个程序背景（含刊头）。
- 启用背景后，卡片自动变为半透明悬浮（毛玻璃），刊头同步透明——**仅在有背景时生效**。
- 「虚化」（0–30px）与「暗化」（0–70%）滑杆实时可调。
- 自定义背景优先级高于主题自带背景；点「移除」后回落到当前主题的背景（无背景主题则恢复纯色）。
- 调整值**按来源分别记忆**：自定义背景与每个主题各存一套，互不影响。

### 浏览器联动
- 开关控制是否接受浏览器扩展提交网址（本机端口 17820）。
- 「开机自动启动」让拾址随系统启动，保证随时可收录。
- 「打开扩展目录」直接打开 `拾址/extension` 文件夹，方便在浏览器里选择加载。

**安装扩展**（Edge / Chrome 通用）
1. 打开 `edge://extensions` 或 `chrome://extensions`
2. 开启**开发人员模式**
3. 点**加载解压缩的扩展**，选择 `拾址/extension` 目录

**扩展菜单**

| 位置 | 菜单项 | 行为 |
| --- | --- | --- |
| 页面右键 | 手动收录 | 唤起拾址窗口，打开预填好的录入弹层 |
| 页面右键 | 快速收录 | 静默入库，不打断浏览 |
| 链接右键 | 手动收录此链接 / 快速收录此链接 | 收录该链接而非当前页 |

重复网址不会新增：手动收录会跳到已有卡片并闪烁，快速收录给出提示。

## 习惯词典

记录「域名 → 分类」的对应关系，**来源是你自己的归类动作**：
手动收录或编辑时给某个域名指定了分类，就会被记下来；下次同类域名直接套用，不再询问。

- 同一域名以**最近一次**指定为准。
- 没有指定分类的条目不会写入词典。
- 列表里可单条移除，或整体清空。

自动分类的优先级：**习惯词典 > 域名直查 > 关键词规则 > AI**。
也就是说，哪怕 AI 认为是「开发」，只要你曾把这个域名归为「工具」，就听你的。

## 分类管理

- **增加**：输入名称后点「添加」（或回车），最多 10 字，重复名称会被拦下。
- **删除**：点分类右侧的 ×。删除后，原本属于该分类的卡片**统一归入「其它」**，卡片本身不会丢。
- **「其它」不可删除**——它是兜底分类。
- 也可以直接在录入弹层的分类一行输入新名称（「+ 新分类」），效果相同。
- 新加的分类会立刻出现在：录入弹层的分类选项、首页分类筛选、以及 AI 的候选分类里。

## AI 配置

- 打开开关并**填全接口地址、API Key、模型**后，AI 才真正生效（缺任一项都不会发起请求）。
- 生效时机：**仅在录入时**（快速收录入库后、手动收录打开弹层时）。不会去改动你已经存在的条目。
- AI 负责两件事：补上**分类**，以及写一句 **≤20 字的用途**。
- 结果只是**建议**：手动收录时会在弹层里预选并标注「AI 建议」，分类与用途都可以随手改；快速收录写入后，你也可以随时编辑。改过之后，这条分类还会被记进习惯词典。
- AI 只能在你已有的分类里选，**不会新建分类**；拿不准时归到「其它」。
- 「测试连接」会用 MDN 作样例跑一次，返回可用性与示例结果。

**隐私**：只向 AI 接口发送网址、标题与页面描述（meta description），**不发送正文**；开关关闭时全程离线。

**接口要求**：兼容 OpenAI 的 `/chat/completions`，填 Base URL（如 `https://api.example.com/v1`）即可，程序会自动补全路径。
