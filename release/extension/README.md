# 拾址 · 浏览器扩展

把正在看的页面、或者某个链接，一键收进桌面上的「拾址」。

扩展本身**不存储任何数据**，只把网址交给本机运行的拾址（HTTP 桥 `127.0.0.1:17820`），
数据文件仍然只由拾址自己写，不会出现两个进程同时改库的冲突。

## 安装（Edge / Chrome 通用）

1. 打开扩展管理页
   - Edge：`edge://extensions`
   - Chrome：`chrome://extensions`
2. 打开左下角（Edge）或右上角（Chrome）的 **开发人员模式**
3. 点 **加载解压缩的扩展**，选择本目录（`weblib/extension`）
4. 确认列表里出现「拾址 · SHIZHI」即完成

> 拾址里也有一键入口：⋮ 菜单 → 设置 → 自定义 → 浏览器联动 → **打开扩展目录**，
> 会直接把这个文件夹在资源管理器里打开，复制路径粘贴到「选择文件夹」即可。

## 用法

| 位置 | 菜单项 | 行为 |
| --- | --- | --- |
| 页面空白处右键 | **加入拾址…** | 唤出拾址窗口，打开预填好的录入弹层（自动抓标题与图标），你补一句用途 |
| 页面空白处右键 | **快速收录到拾址** | 静默入库，不打断浏览，拾址里弹提示 |
| 链接上右键 | **将此链接加入拾址…** | 同上，但收录的是这个链接而不是当前页 |
| 链接上右键 | **快速收录此链接** | 同上，静默版 |

- 网址重复时不会新增：编辑模式会跳到已有卡片并闪一下，快速模式提示「已经在拾址里了」。
- 拾址没运行时，扩展会发一条系统通知提醒你先启动它。

## 权限说明

| 权限 | 为什么需要 |
| --- | --- |
| `contextMenus` | 添加右键菜单项 |
| `activeTab` / `scripting` | 读取当前页标题（仅在右键触发的这一次生效，不常驻读取） |
| `notifications` | 拾址未运行或收录失败时提示 |
| `http://127.0.0.1:17820/*` | 只访问本机的拾址，不碰任何外部网络 |

## 常见问题

**右键菜单里没有？** 扩展未启用或已卸载；回到扩展页确认「拾址 · SHIZHI」是开启状态。

**提示「连不上拾址」？** 拾址没启动。建议打开「开机自动启动」（设置 → 浏览器联动），
这样随时都能收录。

**端口被占用？** 拾址设置里会显示「端口被占用」，通常是开了两个实例；关掉多余的那个即可
（新版已加单实例锁，重复启动会自动聚焦到已开的窗口）。
