# 拾址 · SHIZHI

一个只做一件事的本地网址速查台：把常去的网站收进来，写清用途，以后只在这里找，不用再翻浏览器的收藏夹。

- 完全本地运行，数据存在你自己电脑上，不上传任何服务器
- 支持自定义背景与五套主题
- 可从浏览器右键一键收录当前页面或某个链接

---

## 快速开始

1. 双击 **`拾址.exe`**（便携版，不用安装）
2. 点右上角的 **圆圈加号**，粘贴网址 → 自动抓取名称和图标 → 写一句用途 → 收录
3. 点卡片，用默认浏览器打开

## 录入网址的三种方式

### 1. 手动新增
点圆圈加号，粘贴网址后会**自动抓取网站名称与图标**，抓不到时用域名首字母生成一枚彩色字母标记。

### 2. 浏览器右键（推荐）
安装扩展后，在网页上右键：

| 菜单项 | 行为 |
| --- | --- |
| **手动收录** | 唤起拾址窗口，打开已预填好的录入弹层，你补一句用途 |
| **快速收录** | 静默入库，不打断浏览；标题和图标随后自动补全 |
| **手动收录此链接** / **快速收录此链接** | 对着链接右键，收录该链接而不是当前页 |

重复网址不会新增：手动收录会跳到已有卡片并闪烁，快速收录给出提示。

**安装扩展**（Edge / Chrome 通用）
1. 打开 `edge://extensions` 或 `chrome://extensions`
2. 开启**开发人员模式**
3. 点**加载解压缩的扩展**，选择本目录下的 `extension` 文件夹

### 3. 导入浏览器书签
⋮ 菜单 → **导入浏览器书签**，选择一个导出的书签 HTML 文件。会按网址去重，文件夹名会变成分类。

## 整理

- **分类与排序**：点刊头的滑杆图标，上半是分类（带条数），下半是排序方式（最近访问 / 最近添加 / 访问最多 / 按名称）
- **标签**：每条最多 4 个，检索时能命中
- **检索**：`Ctrl + K` 聚焦，输入即筛；`Enter` 直接打开第一条
- **导出备份**：⋮ 菜单 → 导出 JSON 备份

---

## 个性化（⋮ → 设置）

设置首页列出四个栏目，点进去是具体内容。

### 自定义
- **主题**：纸 / 夜读 / 暮色 / 松墨 / 夜航。后三套自带背景图，配色、强调色、卡片透明度都随之变化
- **背景**：点标题栏的**图片图标**进入设置页。可导入自己的图片，按窗口比例**裁剪后铺满整个背景**（含刊头）；启用后卡片自动变为半透明悬浮。虚化与暗化两个滑杆可调，且**每个主题、自定义背景各记一套数值**
- **浏览器联动**：开关接受扩展提交、开机自动启动、一键打开扩展目录

### 习惯词典
记录「域名 → 分类」的对应关系，来源是你自己的归类动作。你给某个域名归过类，下次同类直接套用。可单条移除或整体清空（清空有二次确认）。

### 分类管理
- 点标题栏**圆圈加号**进入添加页
- 列表每行显示分类名与条目数，右侧**垃圾桶**删除
- 删除分类后，原本属于它的卡片**统一归入「其它」**，卡片不丢
- 「其它」不可删除，它是兜底分类

### AI 配置
打开开关并填全接口地址 / API Key / 模型后生效：
- **只在录入时**调用，不会改动已有条目
- 一次请求同时给出**分类**和一句 **≤20 字的用途**
- 结果只是建议，随时可改；改过之后会记进习惯词典
- 只发送网址、标题和页面描述，**不发送正文**；开关关闭时全程离线

---

## 自动分类是怎么判断的

收录时按四层递进，命中即止：

1. **你的习惯词典** —— 你手动归过类的同类域名，优先级最高
2. **域名直查** —— 常见站点的固定映射
3. **关键词规则** —— 域名 3 分 / 标题 2 分 / 描述与网址 1 分，够 2 分才采纳
4. **AI**（需手动开启）—— 只在前面都没把握时问

**都不中 → 归入「其它」，绝不瞎猜。** 而且**分类体系只能由你手动添加**，AI 和规则都不会新建分类；你加过之后，AI 才会使用它。

## 数据

- 存放位置：`%APPDATA%\shizhi\library.json`（⋮ 菜单 → 打开数据目录）
- 每次写入都是**原子操作**（临时文件 + 重命名），并自动留一份 `.bak` 备份；主文件损坏会自动回退，不会丢数据
- 想换机器：把 `library.json` 拷过去，或用「导出备份 / 导入书签」

## 常见问题

**右键菜单里没有「手动收录」？** 扩展没启用或被浏览器禁用，回到扩展页确认「拾址」是开启状态。

**扩展提示"连不上拾址"？** 拾址没启动。建议在「设置 → 自定义 → 浏览器联动」里打开开机自动启动。

**换主题后卡片看不清？** 提高「暗化」数值（设置 → 自定义 → 背景），或换回「纸」主题。

**能不能同时开两个？** 不能，程序有单实例锁；重复启动会聚焦到已开的窗口。
